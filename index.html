01 · 小红书 · AI 产品经理实习生

Flick 与「问 AI」

企业内部 AI 知识发现与分发产品
痛点公司大量业务经验沉淀在文档里，员工找不到、看不到、用不上，知识复用率很低。
理想态让对的知识主动找到对的人。打开 Flick 就能看到和自己团队相关的经验，有问题直接问 AI，答案有据可查。

核心功能，能带来什么

  • 关注按团队和话题关注；「猜你想关注」根据组织关系、搜索和浏览实时推荐并给出理由，关注后内容直接进入关注流。每个人都能聚焦在自己想看的内容上。
  • AI 内容加工与分发上传文档后，AI 经过预筛、事实审核、授权准入和重要度评分，加工成带分类和标签的知识卡片，再按广泛推荐、定向推荐、保留检索分层分发。好内容被更多人看到，不相关的不打扰。
  • 搜索与问 AI从顶部搜索进入，先检索企业知识库、校验权限，再生成回答并附上来源，用户可以反馈不准确。回答可信，也能持续变好。

02 · 小红书 · AI 产品经理实习生

Colead 会议助手

贯穿会前、会中、会后的会议 Agent
痛点会前材料分散，会中容易跑题，会后纪要和待办靠人工整理；很多事要开好几次会才能推进，上一场说了什么也很难找回。
理想态像车里的智能座舱助手：平时安静地记，需要时一叫就到，记得每一场会的来龙去脉，而且越用越懂你。

核心功能，能带来什么

  • 会前确认你的身份和角色（主持还是参会），收集材料，生成为你准备的简报。
  • 会中静默记录，按会前目标跟踪进度，跑题时主动提醒；“小红小红”一叫就出来总结。
  • 会后生成思维导图和每个人的待办，到期前提醒。
  • 三层知识库（左侧栏「知识库」）个人知识库围绕你本人；会议知识库按目标、节奏和结论打包，承接多场会议的上下文；企业知识库基于 dibp Agent 查询公司内部知识。会议之外，用一句模糊的描述也能找回资料。
  • 个人 Harness（规划中，左侧栏「Harness」）沉淀你的偏好、决策、近期关注、容易丢失的上下文和反复回顾的内容，按权重调用，让 AI 越来越懂你。

03 · 个人项目 · 产品设计与 AI Coding

懂行 · 新人入行词典

一个会自己扩充的行话词库
痛点新人和校招生刚进一个行业，会上满是 Agent、口径、对齐这样的词。查百科太学术，问同事又不好意思。我在汽车、电商、互联网几段实习里反复遇到，一次面试后面试官也建议我多补 Agent 知识，于是把自己的学习过程做成了产品。
理想态像背单词一样入行：搜一个词，三秒看到人话解释和真实用法；词库跟着行业热词自己更新，查不到的词提交后由 Agent 补全。

核心功能，能带来什么

  • 发现首页只有一个搜索框，聚焦的时候给出「猜你想搜」；下面按 AI、数据、职场黑话三本词书浏览，新人可以按书一个个看过去。
  • 词条每个词讲四件事：全称、人话解释、打个比方、实际场景里怎么用，再标出容易混淆的地方和参考来源。
  • 我的词库进来先看到收藏的单个词，再按自建合集整理，和小红书、抖音的「我的」页一样，先看内容再看分组。
  • 申请收录搜不到时一键申请，Agent 查用法、补全释义后收进词库，进度在「我的申请」里能看到。
  • 自动扩充（规划中）接入小红书内部的 dibp Agent 和关注 AI 行业热词的 Hot AI Agent 发现新词，再用 Perplexity 这样的检索后端生成解释，审核后补进词库。
懂行 · 离线设计预览
可以直接搜词、点开词条、收藏到合集、申请收录；离线预览里的操作只在本次打开中保留。

和其他产品有什么不同

  • 对比百科和搜索引擎解释写给新人看，不堆定义；每个词都放回会议和工作场景里讲，还会提醒容易混淆的地方。
  • 对比静态术语表词库会自己长大：热词由 Agent 发现，缺词由用户触发，收录后可以追溯来源，不会过时。
04 · 特斯拉 · 数据产品实习生

售后运营数据看板

把静态 Excel 周报升级为交互式数据产品
痛点售后数据散落在静态 Excel 里，制作耗时、口径不一，管理层看不出哪家店、哪个指标出了问题。
理想态打开看板就知道“哪家店、哪个指标、该先管谁”。

核心功能，能带来什么

  • 统一口径的分层指标FRFT、Key to Key 等指标口径统一，各方看的是同一套数。
  • 大区一列、门店一列先看大区，再下钻到单店。
  • 按关注度排序，异常突出综合达标差距、环比变化和工单量排序；未达标标红、环比恶化标黄，问题门店一眼可见。
  • 沟通工具拿着看板和门店经理逐店对齐问题、跟进改善。

05 · Ubras · AI 产品测试开发实习生

对话式 AI 经营报告

飞书 × 阿里云 × BI 平台的跨平台工作流
痛点业务人员写经营报告，要在 BI 平台逐一翻看大量看板再手工整合，单份约 20 分钟。
理想态在飞书里说一句话，几分钟后在同一个对话里收到一份数据准确、带结论的完整报告。

核心功能，能带来什么

  • 一句话下任务在每天都用的飞书里用自然语言提需求，不用切到 BI 平台。
  • 智能体整合多张报表「神笔」智能体在 BI 平台查询多张报表，整合成带结论的完整报告。
  • 异步生成、自动推回用户 ID 和报告 ID 关联，生成完自动推回发起人，不用等着。
  • 数据复核输出前和源报表核对关键数字，保证报告可信。
