# 懂行 · 每天背一组行话

新人入行的行话词典。刚进一个行业，就像刚开始学英语：先把这个行业里大家常说的词背下来，是入门的第一步。懂行把 AI、数据和职场黑话做成「百词斩」式的每日词卡，每天刷一组，翻面看意思，认识的间隔越拉越长，不认识的当天再来一次。

在线使用：<https://qiaojingjing01.github.io/My-project/donghang/>

## 现在能做什么

- **今日**：选一本词书（AI、数据、职场黑话或全部），每天背 10、20 或 30 个。先复习到期的词，再学新词。
- **词卡**：正面只有词。右滑（或点「认识」）直接进入下一个，4 秒内可以撤回；左滑（或点「不认识」）翻面看意思；也可以先点卡片翻面看一眼再选。背面有人话解释、打个比方、实际这样用、容易弄错的地方。电脑上可以用键盘：→ 认识、← 不认识、↓ 模糊、空格翻面。
- **间隔复习**：认识的词下次出现的间隔依次是 1、2、4、7、15、30 天；模糊的明天再来；不认识的在这一组里隔 3 张再出现一次。
- **发现**：一个大词库。居中搜索，聚焦时给出 12 个「猜你想搜」（三本词书按配额推荐，可以换一批）；按词书浏览全部词卡；搜不到的词一键申请收录。
- **我的**：已掌握、学习中、生词、打卡天数；生词本可以单独背；能看到自己申请收录的词。
- 学习进度只存在当前浏览器里，不上传。

## 目录

```
index.html        页面骨架
style.css         样式
app.js            背词流程、复习算法、发现和我的
data/words.json   词库（58 个词，三本词书）
```

本地预览：在这个目录下运行 `python3 -m http.server`，再打开 <http://localhost:8000>。直接双击 `index.html` 时，浏览器会拦截读取词库。

## 词条格式

```json
{
  "id": 8,
  "word": "RAG",
  "alt": "检索增强生成",
  "book": "ai",
  "cat": "知识与检索",
  "definition": "先检索相关资料，再把资料提供给模型辅助回答。",
  "analogy": "像开卷考试，先翻资料再作答。",
  "example": "……",
  "caution": "……",
  "source": "人工整理",
  "updated": "2026-11-04"
}
```

`word` 是卡片正面显示的说法（大家口头怎么叫就写什么），`alt` 是另一种叫法。

## 下一步：让词库自己长大

目标是把「找新词、写解释、审核入库」交给 Agent，人只做最后的审核。计划用 GitHub Actions 每天跑一次，全部基于开源项目：

| 环节 | 做什么 | 打算用的开源项目 |
|---|---|---|
| 发现新词 | 每天抓取 AI 行业资讯、论文标题和技术博客，统计新出现、出现频率上升的词 | [Crawl4AI](https://github.com/unclecode/crawl4ai) 抓取网页，RSS 订阅资讯源 |
| 查资料 | 对每个候选词联网检索，汇总权威来源 | [Perplexica](https://github.com/ItzCrazyKns/Perplexica)（开源版 Perplexity）或 [GPT Researcher](https://github.com/assafelovic/gpt-researcher) |
| 写解释 | 按词条格式生成人话解释、比方、用法和易错点，必须附来源 | 通义千问等国产开源模型，可通过 API 或本地部署调用 |
| 审核入库 | Agent 把新词条提交成 Pull Request，人工审核通过后合并，网页自动更新 | GitHub Actions + Pull Request |
| 复习算法 | 把现在的简化间隔复习升级为更准的记忆模型 | [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)（FSRS 算法） |

用户在词典里搜不到的词，也会进入候选列表，优先处理。
