# 王雯菁（Claire）的作品集

在线访问：<https://qiaojingjing01.github.io/My-project/>

| 路径 | 内容 |
|---|---|
| `/` | 3D 作品集「Claire 的林间岛」：拖动旋转，点击营地或用 WASD 走动，查看实习经历、Vibe Coding 作品、知识图谱课题和校园经历 |
| `/portfolio/` | 完整作品集：每个项目的详细案例和可交互 Demo |
| `/donghang/` | 懂行：新人入行的行话词典（独立开源项目） |

3D 场景用 [three.js](https://github.com/mrdoob/three.js) r160 搭建，库文件放在 `vendor/`，不依赖外部 CDN，国内网络也能打开。本地预览：在仓库根目录运行 `python3 -m http.server`，再打开 <http://localhost:8000>。
